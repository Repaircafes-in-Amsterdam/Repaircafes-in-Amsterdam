This agenda is an initiative of volunteers at Repair Cafés in Amsterdam.\
The goal is to make all {props.numRepairCafes} Repair Cafés in Amsterdam more accessible by making them easier to find with their opening hours.

If you would like to add a Repair Café or if any information is incorrect or incomplete, we would greatly appreciate an email. For adding, we prefer to use [this questionnaire](https://forms.gle/AQJHMQ7xQsFJ77b47) (currently in Dutch).

We are looking for board members for a new umbrella foundation for Repair Cafés in Amsterdam, [see join as board member](/en/join-as-boardmember).

The website is open source, [see the source code on Github](https://github.com/Repaircafes-in-Amsterdam/Repaircafes-in-Amsterdam).

All information on this website is Amsterdam specific, for more information on Repair Cafés in general see [repaircafe.org](https://repaircafe.org).
